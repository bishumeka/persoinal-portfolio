# Personal Portfolio — Bishaw Mekitachew

A clean, responsive single-page personal portfolio built with semantic HTML5, CSS3, and vanilla JavaScript.

## Features
- Responsive split-screen hero, about section, 2x2 project grid, and grouped skills
- CSS Custom Properties (`variables.css`) for maintainable color and spacing tokens
- Mobile navigation drawer and one-click email copy with accessible live feedback

## Project Structure
- `index.html` — Semantic page structure and content
- `css/reset.css` — Browser baseline normalization
- `css/variables.css` — Design tokens (colors, typography, 8px spacing scale)
- `css/style.css` — Layout, reusable components, and responsive media queries
- `js/main.js` — Mobile menu toggle and clipboard copy interaction
- `assets/images/` — Portrait media
