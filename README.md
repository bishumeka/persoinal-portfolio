# Personal Portfolio — Bishaw Mekitachew

A responsive single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Structure
- `index.html` — page content
- `css/reset.css` — browser baseline
- `css/variables.css` — colors, fonts, spacing, light and dark themes
- `css/style.css` — layout and components
- `js/main.js` — mobile menu, theme toggle, copy email, contact form
- `assets/images/` — hero images and project screenshots (`project-1.png` to `project-4.png`)
